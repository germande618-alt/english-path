# English Path — английский от A1 до C1 за 16 недель

**Сайт:** https://english-path-three.vercel.app/

Веб‑приложение без сервера и без сборки: открывается локально и деплоится на Vercel как статический сайт. Прогресс хранится в браузере (localStorage); его можно скачать и загрузить на вкладке «Тесты».

## Метод

Собран из подходов с самой сильной научной базой:

1. **Интервальные повторения (SRS, алгоритм SM‑2, как в Anki).** Слово возвращается, когда вы начинаете его забывать: 1 → 3 → ~7 → ~18 дней и дальше. Оценки «Забыл / Трудно / Помню / Легко» подстраивают интервал.
2. **Активное вспоминание.** Знакомые слова нужно написать по памяти (RU → EN, с пропуском в примере), а не только узнать.
3. **Слова в контексте + озвучка.** У каждого слова пример и произношение (британский голос браузера).
4. **Грамматика маленькими порциями.** Правило на русском → примеры → 5–6 упражнений. Тема засчитывается при 80%.
5. **Контрольные тесты по уровням CEFR.** 20 вопросов; 80% открывают следующий уровень. Вводный тест засчитывает уже известные уровни.
6. **Понятный ввод (comprehensible input).** Тексты своего уровня с озвучкой и переводом любого слова по нажатию.
7. **Аудирование и говорение.** Диктант с проверкой по словам и повторение фраз вслух с распознаванием речи (Chrome, Edge, Safari).
8. **Работа над ошибками.** Каждое задание, где вы ошиблись, попадает в отдельный список и уходит из него только после верного ответа.

## Что внутри

| Раздел | Содержимое |
|---|---|
| Слова | 1263 частотных слова и выражения (~250 на уровень) с примерами и озвучкой |
| Грамматика | 45 тем с правилами на русском и упражнениями трёх типов: выбор, вписать слово, собрать предложение |
| Практика | 10 текстов для чтения с вопросами, диктант, говорение, 126 неправильных глаголов |
| Тесты | вводный тест, быстрая проверка, контрольные тесты A1–C1 |
| Прогресс | план на 16 недель, темп слов в день, цель дня, серия дней, прогноз повторений |

Работает офлайн и ставится на телефон как приложение (PWA: «Добавить на главный экран»).

## План

| Недели | Уровень |
|---|---|
| 1–3 | A1 |
| 4–6 | A2 |
| 7–10 | B1 |
| 11–13 | B2 |
| 14–16 | C1 |

Каждый день: повторения → новые слова (темп подсказывается автоматически) → одна тема грамматики → практика дня (чтение, диктант, говорение или глаголы) → тест, когда уровень изучен.

**Честно о сроках:** C1 за 4 месяца требует 1,5–2 часа в день и ежедневного «живого» английского сверх приложения (сериалы, подкасты, чтение, разговор). Приложение даёт структуру и закрепление.

## Запуск локально

Просто откройте `index.html` в браузере. Или:

```bash
npx serve .
# либо
python3 -m http.server 8000
```

## Деплой на Vercel

1. Залейте папку в репозиторий GitHub.
2. На vercel.com → **Add New → Project** → выберите репозиторий → **Deploy** (Framework: *Other*, без команды сборки).
3. Каждый `git push` будет обновлять сайт автоматически.

## Как добавить контент

- Слова: `data/vocab.js` — строка `слово|перевод|пример` в нужный уровень.
- Грамматика: `data/grammar.js` — объект темы с правилом, примерами и упражнениями (`mc` — выбор варианта, `gap` — вписать ответ).

- Тексты: `data/reading.js`, неправильные глаголы: `data/verbs.js`, подсказки при чтении: `data/glossary.js`.
- После изменения файлов увеличьте версию `CACHE` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.
